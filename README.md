## 2 Построение автоматов

### 2.1 ДКА (пункт а)

Ключевая идея: чтобы в любой момент знать, стоит ли на пятой позиции с конца символ `1`, автомат должен «помнить» последние пять прочитанных символов. Поэтому **состояние ДКА — это окно из последних 5 бит цепочки**.

Правило перехода простое — сдвиг окна:

$$q_{b_1b_2b_3b_4b_5} \xrightarrow{\;c\;} q_{b_2b_3b_4b_5c}$$

старший (первый) бит окна выбрасывается, новый символ `c` дописывается справа.

Для цепочек короче пяти символов недостающие позиции слева считаются виртуальными нулями — поэтому начальное состояние не выделяется отдельно, а совпадает с состоянием «всё окно из нулей»: `q00000`.

**Принимающие состояния** — все состояния, у которых старший бит окна равен `1` (то есть символ на нужной позиции действительно `1`).

Поскольку окно состоит из 5 бит, а алфавит бинарный, всего различных состояний-окон получается

$$2^5 = 32$$

Итоговый автомат содержит **32 состояния**.

### 2.2 НКА (пункт б)

Множество {a^n : n ≥ 1} является частным случаем множества {b^m a^k : m, k ≥ 0} при m = 0, k = n, поэтому первое целиком содержится во втором, и итоговый язык эквивалентен `b*a*` — произвольное число символов `b`, за которым следует произвольное число символов `a`.

НКА строится всего на **2 состояниях** (укладывается в лимит ≤ 3):

- `q0` — начальное и принимающее состояние, петля по `b`;
- `q1` — принимающее состояние, петля по `a`;
- перехода из `q1` обратно по `b` нет — возврат к `b` после `a` запрещён.
